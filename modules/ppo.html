1. PPO 在解决什么问题？

策略梯度根据采样轨迹估计期望回报的改进方向。若训练数据来自旧策略，但在同一批数据上对策略反复更新，新策略可能偏离采样分布过远。PPO 用裁剪代理目标来降低过度优化的风险。

rₜ(θ) = πθ(aₜ|sₜ) / πold(aₜ|sₜ)
LCLIP = Eₜ[min(rₜ Aₜ, clip(rₜ, 1−ε, 1+ε) Aₜ)]
关键区别：clip 处理的是概率比率在代理目标中的贡献，不是对参数更新幅度或真实策略变化的硬约束。PPO 仍可能出现较大的策略变化，因此实际实现有时还会监测 KL 并提前停止更新。

2. Actor、Critic 与优势函数

Actor / Policy

给定状态或观测，输出动作分布。连续控制常使用高斯分布，但动作变换和标准差参数化由实现决定。

Critic / Value

估计状态价值 V(s)，作为基线帮助降低策略梯度估计的方差。

Advantage

A(s,a) 估计动作相对该状态平均水平的好坏，而不是单纯的奖励大小。

Entropy

常用作探索正则项。熵下降不一定是坏事，应结合任务成功率和策略多样性判断。

常见联合目标（最大化形式）：
L = LCLIP − cᵥ Lvalue + cₑ H(π)

具体代码可能将目标变成需要最小化的 loss，因此各项符号可能相反；应按实现的优化方向读取。

3. 如何阅读训练日志

指标通常反映什么诊断时的注意点
Return / Success任务表现同时看多个种子、评估场景与波动，不只看最优点。
Approx KL新旧策略的差异估计突然升高时检查学习率、更新轮数、优势尺度和数据处理。
Clip fraction比率触及裁剪区域的样本比例很高不自动意味着训练失败，需要结合 KL 和表现变化。
Entropy策略分布的不确定性快速降低可能代表探索减少，但也取决于任务与参数化。
Value loss价值预测误差受回报尺度影响，应结合解释方差、回报和 bootstrap 处理。

建议把日志判断写成“现象—可能机制—下一项可区分实验”，而不是由单个指标直接下结论。

4. 读代码清单

  1. 定位 rollout / storage，确认采样数据包含哪些字段。
  2. 追踪动作采样、旧策略 log probability 和新策略 log probability。
  3. 检查优势归一化、GAE、终止和时间上限截断（timeout）的处理。
  4. 核对 policy loss、value loss、entropy loss 和各自权重。
  5. 查看学习率调度、梯度裁剪、KL 监测和每批数据的更新轮数。
  6. 确认训练与部署的动作分布处理、动作缩放和归一化一致。
对于机器人策略，还必须确认 action 表示关节位置目标、位置增量、速度还是力矩，以及低层控制器如何执行该 action。
