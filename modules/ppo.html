1. PPO 在解决什么问题？

策略梯度通过采样轨迹估计提高期望回报的方向。若一次更新让新策略与采样数据对应的旧策略差异过大，训练可能不稳定。PPO 使用裁剪目标，抑制概率比率偏离 1 时的过度优化。

rₜ(θ) = πθ(aₜ|sₜ) / πθold(aₜ|sₜ)
Lclip = E[min(rₜAₜ, clip(rₜ, 1−ε, 1+ε)Aₜ)]

2. Actor、Critic 与优势函数

  • Actor / Policy：定义给定状态下的动作分布。
  • Critic：估计 V(s)，为优势估计提供基线。
  • Advantage：衡量某动作相对当前状态平均水平的好坏。
  • Entropy：常用于鼓励探索。
  • Value loss：让价值估计接近回报目标。

3. 训练日志怎么看

  • 平均回报/成功率：任务表现是否提升。
  • Entropy：策略分布是否过早变得确定。
  • Approx KL：新旧策略差异，异常升高时检查学习率与更新轮数。
  • Value loss：需结合回报尺度和价值预测误差判断。
  • Clip fraction：有多少样本的比率触及裁剪区域。

机器人任务中，务必先确认 action 表示关节位置目标、位置增量、速度还是力矩；这会改变动作尺度和控制难度。

4. 读代码清单

  1. 找到 rollout buffer 和采样逻辑。
  2. 确认 log probability 的计算位置。
  3. 检查 advantage 是否归一化。
  4. 核对 done、timeout 与 bootstrap 处理。
  5. 确认 policy loss、value loss、entropy loss 的权重。
