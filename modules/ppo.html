强化学习学习笔记

PPO 近端策略优化算法

从直觉、核心公式，到一个可逐步核算的数字例子，再到训练伪代码与大语言模型中的应用。

目标：理解 PPO 为什么需要概率比率、优势函数与 Clip，以及它们在一次策略更新中如何配合。

0. 一页先看懂 PPO

PPO（Proximal Policy Optimization，近端策略优化）是一种策略梯度强化学习算法。它用当前策略采样数据，再通过裁剪目标函数限制“过度改变策略”带来的优化收益，让更新相对稳定。

① 采样
旧策略与环境交互，收集状态、动作、奖励和旧策略概率。
② 估值
Critic 估计状态价值，使用 TD/GAE 计算优势。
③ 更新
Actor 最大化 PPO-Clip 目标；Critic 拟合回报。
④ 重复
完成若干轮小批量更新后，使用新策略重新采样。
记忆口诀：优势决定“往哪边改”，概率比率衡量“改了多少”，Clip 让过大的有利变化不再获得额外目标收益。

1. 新增基础：MDP（马尔可夫决策过程）

MDP 描述强化学习问题是什么；PPO 则是一种在这个问题中学习行动策略的方法。在进入 PPO 的 Actor、Critic、GAE 之前，先明确智能体如何与环境交互。

MDP = (S, A, P, R, γ)
要素意思迷宫示例在 PPO 中的关联
S：状态空间所有可能的状态机器人当前所在格子状态 sₜ 是 Actor 和 Critic 的输入
A：动作空间所有可选动作上、下、左、右Actor 根据策略分布选择 aₜ
P：状态转移P(s'|s,a)：执行动作后转到下一状态的概率向右通常走到右边一格；随机环境也可能打滑环境执行动作并返回下一状态
R：奖励环境对当前行为/转移给出的反馈每步 −1，到终点额外 +10用于计算回报、TD 误差和 GAE
γ：折扣因子未来奖励在当前回报中的权重γ=0.9 时下一步奖励乘 0.9进入回报和 TD/GAE 计算
马尔可夫性质：状态应包含预测下一状态所需的相关信息。给定当前状态和动作后，下一状态的分布不必再额外依赖完整历史：P(sₜ₊₁ | sₜ,aₜ,历史)=P(sₜ₊₁ | sₜ,aₜ)。若只记录机器人位置，却忽略影响运动的速度，位置可能不是充分的状态。

2. PPO 的组件与符号

符号含义直觉
sₜ时刻 t 的状态智能体当前看到的情况
aₜ时刻 t 采取的动作在该状态下做了什么
πθ(a|s)参数为 θ 的策略对动作的概率Actor 的行为倾向
Vφ(s)Critic 对状态价值的估计从当前状态出发，未来大概能得到多少回报
Q(s,a)状态-动作价值在 s 做 a 后的预期回报
Âₜ优势估计动作比当前基准表现好多少
rₜ(θ)新旧策略概率比新策略相对旧策略改变了多少
ε裁剪阈值，常见起点为 0.2目标函数对概率比变化的敏感范围

Actor-Critic 分工

  • Actor（策略网络）：输出动作分布，学习如何行动。
  • Critic（价值网络）：预测状态价值，为优势估计提供基线。

PPO 通常采用 Actor-Critic 结构，但 PPO-Clip 的核心并不是某一种网络架构，而是它的策略优化目标。

3. 三个核心公式

公式 A：概率比率

rₜ(θ) = πθ(aₜ | sₜ) / πθold(aₜ | sₜ)

若旧策略给某动作的概率为 0.40，新策略为 0.50，则 r = 0.50 / 0.40 = 1.25，也就是该动作的概率相对提高了 25%。

公式 B：优势函数

A(sₜ,aₜ) = Q(sₜ,aₜ) − V(sₜ)

A > 0 表示动作比价值基准预期好；A < 0 表示比预期差。实践中通常用 GAE 估计优势，而不是直接知道真实的 Q 值。

公式 C：PPO-Clip 目标（核心）

LCLIP(θ) = Eₜ [ min( rₜ(θ) Âₜ,
clip(rₜ(θ), 1−ε, 1+ε) Âₜ ) ]

其中 clip(x, 1−ε, 1+ε) 将 x 截到给定区间；min 选择更保守的目标值。算法通常最大化该目标。

重要澄清：Clip 不是把实际策略概率硬性限制在 [0.8, 1.2]，也不是严格的信赖域约束。它裁剪的是目标函数中的概率比率项；实际比率仍可能超出区间。

核心理解：正优势样本的概率提高过头时会被上界保护；负优势样本的概率降低过头时会被下界保护。Clip 对“有利于目标的过大变化”采取保守处理，而不是简单地把所有变化都截断。

5. 从奖励计算优势：一个小型 GAE 例子

GAE（Generalized Advantage Estimation，广义优势估计）把多个时刻的 TD 误差加权累加，通常在偏差与方差之间折中。

δₜ = rₜ + γ V(sₜ₊₁) − V(sₜ)
Âₜ = δₜ + γλ δₜ₊₁ + (γλ)² δₜ₊₂ + …

由于 γλ = 0.72：

Â₂ = 1.60
Â₁ = −0.24 + 0.72×1.60 = 0.912
Â₀ = 1.04 + 0.72×(−0.24) + 0.72²×1.60 ≈ 1.697

这说明优势不只由当前即时奖励决定，后续时刻的 TD 误差也会以衰减权重影响当前优势。真实训练中通常按轨迹批量计算，并正确处理终止与时间截断。

6. Critic 怎么训练？

常见做法是先用优势与价值估计构造回报目标，例如：

R̂ₜ = Âₜ + V(sₜ)

然后最小化价值损失：

Lvalue = Eₜ [ (Vφ(sₜ) − R̂ₜ)² ]

Actor 用优势判断动作相对好坏；Critic 则努力让价值预测接近回报目标。价值网络预测更准确，通常有助于改善优势估计质量。

总损失的常见写法

如果把策略目标写成要最大化的形式：

L = LCLIP − cv Lvalue + ce H(π)

这里 H(π) 是策略熵，鼓励探索。若深度学习代码统一使用“最小化 loss”的约定，通常会把策略目标取负，并相应组合价值损失与熵项。具体符号会因实现而不同。

7. PPO 的训练循环（伪代码）

初始化 Actor 参数 θ、Critic 参数 φ

重复每一轮：
    使用旧策略 π_old 与环境交互
    收集 states、actions、rewards、done、log_probs_old、values
    用奖励、价值估计计算 returns 和 advantages（常用 GAE）

    对同一批数据进行若干 epoch：
        划分 minibatches
        计算 log_probs_new
        ratio = exp(log_probs_new - log_probs_old)
        surrogate1 = ratio * advantages
        surrogate2 = clip(ratio, 1-ε, 1+ε) * advantages
        policy_objective = mean(min(surrogate1, surrogate2))
        value_loss = mean((values_new - returns)^2)
        entropy = mean(policy_entropy)

        按实现约定组合目标并反向传播
        更新 Actor / Critic 参数

    将更新后的策略用于下一轮采样
实现提示：用 log probability 相减再取指数，通常比直接计算两个很小的概率之比更稳定。实践中还会涉及优势标准化、梯度裁剪、学习率调度、价值损失裁剪或 KL 监控等工程选项。

8. PPO 的优点、局限与常见误解

优点

  • 目标函数简单，容易与自动微分和小批量优化结合。
  • 在很多连续控制与离散动作任务中表现稳健。
  • 比 TRPO 更容易实现，不需要每一步都求解复杂的信赖域约束问题。

局限

  • 属于 on-policy 方法，采样数据通常不能像离策略方法那样长期重复利用。
  • 性能对奖励尺度、优势估计、学习率、更新轮数等超参数仍较敏感。
  • Clip 并不保证策略分布变化一定很小，也不保证每轮更新都提升真实环境回报。

常见误解

  • 误解：Clip 把真实概率比硬性限制在 [0.8, 1.2]。
    正确：裁剪的是目标函数中的比率项，真实比率可能越界。
  • 误解：PPO 每次只更新一次。
    正确：通常会对一批新采样数据做多个 epoch 的小批量更新。
  • 误解：优势为正就代表动作一定拿到正奖励。
    正确：优势表示相对于价值基准的好坏，不等同于即时奖励的正负。

9. PPO 在大语言模型 RLHF 中的角色

在语言模型中，状态可以理解为已生成的上下文，动作是下一个 Token。策略模型产生回答，奖励模型依据偏好给出奖励，PPO 再更新语言模型。

语言模型
根据上下文逐 Token 生成回答。
奖励模型
为回答质量或偏好提供标量奖励。
PPO 更新
根据优势更新策略，通常另加 KL 惩罚，避免偏离参考模型过远。
区分两个机制：PPO-Clip 限制裁剪目标对过大概率比变化的收益；RLHF 中的 KL 惩罚衡量当前策略与参考策略的分布差异。二者可以同时存在，但不是同一项。
