注意力机制

理解 Q/K/V、缩放点积注意力、多头机制，以及它在机器人策略中的潜在作用。

← 返回学习门户

1. 核心公式

Attention(Q,K,V) = softmax(QKᵀ / √dₖ)V
  • Query：当前 token 想检索什么。
  • Key：每个 token 用于匹配的特征。
  • Value：匹配后被加权汇总的信息。
  • √dₖ：控制点积随维度增长的尺度，避免 softmax 过于尖锐。

2. 张量形状

输入（batch_first=True）：[B, T, D]
Q: [B, Tq, Dk] K: [B, Tk, Dk] V: [B, Tk, Dv]
注意力权重： [B, heads, Tq, Tk]
输出： [B, Tq, D]

实现时重点检查 batch 维、序列维、embedding 维，以及 mask 的广播规则。

3. G1 / 强化学习场景

  • 将历史观测编码为时间序列，建模延迟与动态信息。
  • 将身体部位或关节组编码为 token，建模跨部位关联。
  • 将指令、地形或参考动作作为条件，探索交叉注意力。

注意力不是天然更好。与 MLP 基线比较时应固定训练预算、数据量、随机种子和评估场景，并记录推理耗时。
