1. MDP 五元组

M = (S, A, P, R, γ)
符号含义机器人中的例子
S状态空间仿真内部完整状态或定义好的策略输入。
A动作空间关节目标、动作增量或力矩等。
P(s′|s,a)状态转移物理动力学、接触、环境变化和执行器响应。
R(s,a,s′)奖励函数速度跟踪、稳定性、能耗或任务完成奖励。
γ折扣因子衡量未来奖励相对当前奖励的权重。

2. 状态不等于观测

在理想 MDP 中，状态包含了预测未来所需的信息。但机器人策略通常只收到观测向量 oₜ，它可能遗漏真实速度、接触状态或环境几何。此时问题可能更接近部分可观测决策过程（POMDP）。

环境状态 sₜ → 传感器 / 观测构建 → oₜ → policy → aₜ

历史帧、循环网络或 Transformer 可以帮助推断隐藏状态，但是否必要，要由观测定义和任务需求决定。

3. 回报与价值函数

Gₜ = rₜ + γ rₜ₊₁ + γ² rₜ₊₂ + …
Vᵖ(s) = Eᵖ[Gₜ | sₜ=s]
Qᵖ(s,a) = Eᵖ[Gₜ | sₜ=s, aₜ=a]
Aᵖ(s,a) = Qᵖ(s,a) − Vᵖ(s)

回报是轨迹上的折扣奖励和；价值函数是在策略下对未来回报的期望。优势函数描述某个动作相对当前状态基线的价值差。

4. 机器人任务如何映射到 MDP

  • 观测：每个字段的单位、坐标系、顺序、是否归一化、是否包含历史。
  • 动作：动作维度、物理意义、缩放、低层控制接口和安全限制。
  • 奖励：各项权重、量纲、随时间还是随步数累积、是否存在投机行为。
  • 终止：真正失败、成功终止、时间上限截断，以及各自的 bootstrap 规则。
  • 评估：训练环境和独立测试环境是否隔离，测试协议是否预先固定。
读项目时不要只看 reward 函数。环境 reset、termination、观测生成、控制器和采样循环共同决定实际学习问题。
