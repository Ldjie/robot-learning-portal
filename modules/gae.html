1. TD 残差

δₜ = rₜ + γV(sₜ₊₁) − V(sₜ)

TD 残差衡量一步奖励加下一状态价值与当前价值估计之间的差异。边界处是否使用 bootstrap、以及终止 mask 如何处理，会影响残差的计算。

2. GAE：累积多个时间步的 TD 残差

Âₜ = δₜ + (γλ)δₜ₊₁ + (γλ)²δₜ₊₂ + …

γ 决定未来奖励的折扣；λ 控制残差向后累积的权重。较小的 λ 通常更偏向短范围估计、可能有较低方差但偏差较大；较大的 λ 纳入更多后续信息，方差可能变大。

实际实现一般用反向递推而不是显式求无穷级数，并在 episode 边界应用 mask。

3. terminal 与 timeout 不应混为一谈

情况含义常见处理考虑
真正 terminal任务失败或成功等，当前 episode 确实结束。一般不从终止后的状态 bootstrap。
Time limit timeout达到仿真步数上限，但物理任务未必真正失败。某些实现会继续使用终止前最后状态的价值进行 bootstrap。

不要只看一个 done 变量就推断处理正确。应确认环境是否区分 termination 与 truncation，并检查存储、回报计算和 GAE 递推中的 mask。

4. 实现检查清单

  • 确认 rollout buffer 中 reward、value、done/timeout 和最后状态字段的语义。
  • 确认最后一个状态的 bootstrap value 如何计算。
  • 确认递推不会跨 episode 累积优势。
  • 确认 advantage normalization 是否开启，以及归一化维度。
  • 将优势统计与 return、value loss 和策略更新日志一起分析。
