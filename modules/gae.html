GAE 优势估计

理解 TD 残差与 λ 参数如何控制优势估计的偏差和方差。

← 返回学习门户

1. TD 残差

δₜ = rₜ + γV(sₜ₊₁) − V(sₜ)

TD 残差衡量一步奖励加下一状态价值，与当前价值预测之间的差异。

2. GAE 公式

Âₜ = δₜ + (γλ)δₜ₊₁ + (γλ)²δₜ₊₂ + …

γ 控制未来奖励折扣；λ 控制残差向后累积的长度。较小 λ 通常更偏向短视、方差较低；较大 λ 使用更多未来信息，但方差可能更高。

3. 实现检查

  • 区分真正终止（terminal）与时间上限截断（timeout）。
  • 确认最后一个状态的 bootstrap value 是否正确。
  • 检查 done mask 是否阻断跨 episode 的递推。
  • 确认 advantage normalization 是否开启。
