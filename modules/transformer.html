1. 一个 Encoder block

输入 → Multi-Head Self-Attention → 残差 + LayerNorm
→ Feed-Forward Network → 残差 + LayerNorm

注意力在 token 之间混合信息，前馈网络逐 token 变换特征；残差和归一化有助于优化深层网络。

2. 为什么需要位置/时间信息？

自注意力本身对 token 排列不敏感。序列任务通常需要位置编码、时间戳、相对位置偏置，或通过结构设计注入顺序信息。

3. 机器人序列建模

  • 输入可以是连续多帧 proprioception（本体感觉）。
  • 每帧可拼接关节位置/速度、基座姿态、角速度与指令。
  • 动作输出可以对应当前帧，也可以对应预测未来动作；训练目标要与时间对齐。
  • 检查序列长度、padding mask、因果 mask 和训练/推理一致性。
