G1 AME 网络结构

记录 Policy 网络、张量形状与 Attention 插入位置。

← 返回学习门户

1. 网络结构记录表

  • 输入字段：关节位置/速度、基座姿态、角速度、指令、历史帧等。
  • 编码方式：直接拼接、分组 MLP、时序 encoder 或 token 化。
  • 特征维度：输入维度、hidden size、head 数、层数。
  • 输出头：动作均值、标准差、价值估计。

2. 追踪张量流

obs → normalize / split → encoder → attention → policy trunk → action distribution

在每个节点记录 shape、dtype、device、是否包含时间维、是否共享 Actor/Critic 参数。

3. 排查常见问题

  • batch_first 设置与输入 shape 不一致。
  • mask 的 True/False 语义与框架 API 不一致。
  • 历史序列顺序或时间对齐错误。
  • 新增模块后参数初始化、学习率和梯度尺度变化。
  • 推理路径与训练路径的归一化不一致。
