G1 AME 项目总览

项目知识入口：先建立仓库地图，再核实算法与网络实现。

← 返回学习门户

1. 项目地图模板

  • 训练入口：命令行、配置文件与 runner。
  • 环境定义：机器人模型、观测、动作、奖励、reset。
  • 算法实现：PPO / rollout storage / optimizer。
  • 策略网络：Actor、Critic、encoder、attention 模块。
  • 部署/评估：checkpoint、推理接口、控制频率。

2. 建议的阅读顺序

  1. 从 README 和运行脚本确认训练流程。
  2. 从配置文件确定 observation/action 维度。
  3. 追踪环境如何组装 observation 和 reward。
  4. 追踪 policy forward 到 action 输出。
  5. 最后研究 attention 的插入位置和训练目标。

“AME”的具体定义和实现应以你实际项目仓库、论文或文档为准，不要只凭缩写推断。
