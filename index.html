算法专项

PPO：近端策略优化

PPO 通过限制新旧策略更新幅度，降低策略梯度更新过猛造成的不稳定。重点是理解概率比率、优势函数和裁剪目标之间的关系。

核心目标函数

rₜ(θ) = πθ(aₜ|sₜ) / πθold(aₜ|sₜ)
LCLIP = Eₜ[min(rₜ Aₜ, clip(rₜ, 1−ε, 1+ε) Aₜ)]

当优势 Aₜ 为正时，策略希望提高该动作概率；当优势为负时，策略希望降低其概率。clip 限制比率对目标函数的有利方向贡献，避免单次更新过大。

训练中的关键组成

  • Actor：给出动作分布，而不只是动作均值。
  • Critic：估计状态价值 V(s)，帮助计算优势。
  • GAE：在偏差与方差之间折中估计优势。
  • Entropy：鼓励策略保留探索性。
  • Value loss：训练价值网络拟合回报目标。
机器人任务提示：先确认 action 是关节位置目标、关节增量还是力矩；不同 action 定义会改变策略学习难度与安全性。

网络结构专项

注意力机制与 Transformer

注意力让网络根据当前查询动态聚合不同输入位置的信息。它可以用于历史观测编码、身体部位特征交互或多模态融合，但不意味着必然优于 MLP。

Scaled Dot-Product Attention

Attention(Q,K,V) = softmax(QKᵀ / √dₖ) V
  • Q（Query）：当前要寻找什么信息。
  • K（Key）：各输入位置提供什么匹配线索。
  • V（Value）：匹配后实际聚合的信息内容。
  • Multi-Head：并行学习不同子空间中的关系，再拼接映射。

机器人策略中可探索的用法

历史观测编码

把过去若干帧的关节状态、基座姿态、速度与指令作为序列输入，学习时序依赖。

身体部位交互

把不同关节组或身体部位编码为 token，探索跨部位的信息融合。

条件信息融合

研究目标速度、地形或参考动作作为条件时，是否适合 Cross-Attention。

对照基线

固定训练预算和随机种子，对比 MLP、轻量时序模型与 Attention。

PyTorch 形状提醒

输入常见形状（batch_first=True）：[batch, seq_len, embed_dim]
输出形状通常与 query 的前两维对应：[batch, seq_len, embed_dim]
不要只看 attention 权重图就断言模型“理解”了某个关节。应结合消融实验、性能指标、稳定性与推理耗时验证。

机器人基础

运动学、动力学与全身控制

需要掌握的概念

  • 坐标系：世界系、基座系、关节局部系与传感器系。
  • 正运动学：由关节位置得到末端位姿。
  • 逆运动学：求解达到目标位姿的关节配置。
  • 刚体动力学：质量矩阵、科氏/离心项、重力项和外力。
  • 接触动力学：足底接触、摩擦锥、支撑相与摆动相。
  • 全身控制（WBC）：协调任务空间目标、关节约束与接触约束。
M(q) q̈ + C(q,q̇) q̇ + g(q) = τ + J(q)ᵀ f
强化学习策略通常不是脱离控制系统单独工作的：观测定义、低层控制器、PD 增益、动作缩放和仿真接触模型都会影响训练结果。

实验时重点追踪

  • 环境与机器人配置：关节顺序、限位、质量、惯量、碰撞几何。
  • 观测：归一化、历史堆叠、噪声、延迟与缺失值处理。
  • 奖励：任务目标、姿态、能耗、平滑性、接触与存活奖励。
  • 随机化：质量、摩擦、执行器、传感器噪声、延迟与地形。
  • 评估：多随机种子、不同地形、扰动恢复、跌倒率和能耗。
