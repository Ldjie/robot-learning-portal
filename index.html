PPO：近端策略优化

理解采样策略与更新策略的关系，再把目标函数映射到代码中的 log probability、优势估计和优化器。

核心目标

rₜ(θ) = exp(log πθ(aₜ|sₜ) − log πold(aₜ|sₜ)) Lclip = Eₜ[min(rₜ Aₜ, clip(rₜ, 1−ε, 1+ε) Aₜ)]

当优势为正时，优化通常倾向于提高该动作的概率；当优势为负时，倾向于降低概率。裁剪针对概率比率在代理目标中的贡献，并不是对参数变化、KL 或真实策略变化的硬约束。

策略、价值与熵

  • Actor：定义动作分布。连续控制策略经常使用高斯分布，但具体分布、标准差参数化和动作变换必须看实现。
  • Critic：估计状态价值，为优势估计提供基线。
  • GAE：通过累计 TD 残差估计优势，在偏差与方差间折中。
  • Entropy：常用于鼓励探索；它的变化应结合任务表现和策略分布判断。
  • Value loss：让价值预测贴近回报目标；具体损失形式由实现决定。

常见的联合优化目标

最大化： Lclip − cᵥ · Lvalue + cₑ · Entropy （有些代码将其改写为需要最小化的 loss，符号可能相反。）
排查顺序建议：先核对 action 定义、log probability 和 done/timeout 处理；再看 Approx KL、clip fraction、entropy、value loss 与成功率的共同变化。任何单项指标都不应独立作为训练好坏的结论。

注意力机制：快速回顾

注意力是内容相关的信息聚合机制，不是自动提升性能的开关。

Attention(Q,K,V) = softmax(QKᵀ / √dₖ) V

Q · Query

用于与各 Key 计算匹配分数的查询表示。

K · Key

提供匹配特征，决定每个 Query 对哪些位置赋予更高分数。

V · Value

被权重加权聚合的信息内容。

多头机制

用不同的可学习投影在多个子空间中计算交互，再拼接并投影。

常见张量形状（示例，不是 AME 实现声明）

X: [B, L, D] Q/K: [B, h, L, dₖ] V: [B, h, L, dᵥ] Attention score: [B, h, L, L] Concat heads: [B, L, h · dᵥ] Output projection: [B, L, Dₒᵤₜ]

例如空间特征 [B, 64, 11, 17] 若把空间维展平，会得到 [B, 64, 187]；但 64 究竟代表通道还是其他含义，必须依据实际张量来源确认。展平后是否需要位置编码，也要根据后续层是否保留空间结构判断。

不要从权重图直接推断因果解释。通过消融、输入干预、跨场景评估和推理延迟，验证注意力是否真正带来收益。

机器人基础运动学 · 动力学 · 接触

机器人控制基础

刚体动力学

M(q) q̈ + C(q,q̇) q̇ + g(q) = τ + J(q)ᵀ f

这是常见的动力学表达形式。变量的具体含义、外力的正负号和广义坐标约定需与具体模型一致。对于浮动基座机器人，并非所有广义自由度都能由关节力矩直接驱动。

需要区分的层次

运动学

坐标变换、正逆运动学、雅可比矩阵和速度映射。

动力学

质量矩阵、科氏/离心项、重力、惯量与外力。

接触与摩擦

单边接触、摩擦锥、支撑相、碰撞几何和求解器参数。

策略执行接口

关节顺序、动作缩放、PD 增益、延迟和控制周期。

出现站立漂移或打滑时，现象本身不足以证明是仿真器错误。应固定策略和初始条件，分别检查摩擦模型、接触参数、控制器、动作输出与扰动测试结果，避免一次改动多个因素。

仿真与 Sim-to-Real

把迁移差距拆开

感知差异

深度图、相机内外参、无效像素、重建误差与高程图生成。

观测差异

字段顺序、归一化、历史缓存、单位、时间戳与延迟。

控制差异

关节映射、控制频率、PD 参数、执行器饱和与动作限幅。

物理差异

质量、惯量、摩擦、接触、地形与外部扰动。

最小实验原则

提出假设 → 选择单一改动 → 固定训练与评估预算 → 多随机种子 / 多初始状态测试 → 记录均值、波动与失败案例

确定性复现只能证明某个条件下的行为可复现，不等同于鲁棒性。评估应事先规定场景、随机种子、扰动、成功标准和终止条件，并区分冒烟测试与完整验证矩阵。

感知输入链（相机策略）

深度图 → 去噪 / 无效值处理 → 坐标变换 → 高程图或视觉编码 → 策略观测 → 动作输出

逐步记录每个阶段的数据形状、坐标系、单位、时间戳和延迟，判断性能下降来自感知、接口、模型还是控制环节。
