机器人强化学习学习门户
========================

入口文件：index.html

目录：
- index.html：学习门户首页，内置 PPO、注意力机制、G1 AME、机器人控制、仿真和个人笔记。
- modules/ppo.html：PPO 深入讲解
- modules/attention.html：注意力机制
- modules/transformer.html：Transformer 基础
- modules/mdp.html：MDP 与强化学习基础
- modules/gae.html：GAE 优势估计
- g1-ame/overview.html：G1 AME 项目总览
- g1-ame/network.html：G1 AME 网络结构
- g1-ame/experiments.html：G1 AME 实验记录

本地预览：
1. 解压 ZIP。
2. 打开 index.html。
3. 点击侧栏或首页的“独立 HTML 专题”链接。

部署：
把解压后的 index.html、modules/ 和 g1-ame/ 一起上传到同一个仓库/网站根目录。
请保持目录结构不变，否则相对链接会失效。

注意：
个人笔记与学习进度存储在浏览器 localStorage 中。换浏览器或设备前，使用门户里的“导出备份”。
