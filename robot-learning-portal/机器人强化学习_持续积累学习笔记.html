01 · MDP：马尔可夫决策过程

基础概念

MDP 是描述智能体与环境交互的数学框架。机器人在时刻 \(t\) 观察状态、执行动作，环境转移到新状态并返回奖励。

MDP = (S, A, P, R, γ)
元素含义人形机器人例子
S 状态空间智能体可观察的状态机身角速度、关节位置与速度、重力方向、目标速度
A 动作空间策略可以选择的动作关节目标位置偏移、目标速度或控制力矩
P 转移规律执行动作后环境如何变化关节控制影响身体姿态、脚底接触和下一时刻状态
R 奖励函数对当前行为给出评价跟踪目标速度得奖励，摔倒或过度用力受惩罚
γ 折扣因子未来奖励的折扣系数决定策略重视近期还是长期结果

回报与价值函数

Gt = rt + γrt+1 + γ²rt+2 + …
Vπ(s) = Eπ[Gt | st=s]

马尔可夫性质的直觉是：如果状态包含了足够的信息，那么给定当前状态和动作后，下一状态不需要再依赖更早的完整历史。实际机器人观测可能不完全，因此有时需要历史帧、状态估计或循环网络。

自测

  • 状态和动作有什么区别？
  • 把“机身高度”直接当作奖励，可能会造成什么行为偏差？
  • 折扣因子 γ 越大，通常意味着什么？

02 · PPO、Actor-Critic 与 GAE

核心算法

Actor-Critic 分工

  • Actor / Policy：根据状态产生动作分布，决定“怎么做”。
  • Critic / Value：估计状态价值，帮助判断结果比预期好还是差。

概率比率与裁剪目标

rt(θ) = πθ(at|st) / πθold(at|st)
LCLIP = E[min(rtAt, clip(rt,1−ε,1+ε)At)]

直觉：PPO 希望提高优势为正的动作概率、降低优势为负的动作概率，但通过裁剪限制单次更新带来的激进变化。实现时通常还会有价值函数损失、熵奖励等项。

GAE：优势估计

δt = rt + γV(st+1) − V(st)
AtGAE = δt + γλδt+1 + (γλ)²δt+2 + …

γ 控制未来回报的折扣；λ 控制 GAE 汇总多个时刻 TD 误差的方式。优势估计的质量会影响 Actor 的更新方向。

训练循环（概念版）

初始化策略参数 θ、价值函数参数 φ
重复：
  用当前策略采集一批轨迹
  计算回报、TD 误差与 GAE 优势
  用 PPO-Clip 更新策略 θ
  用价值函数损失更新 Critic φ
  记录奖励、熵、KL、价值损失等指标
常见误区：PPO-Clip 并不保证策略更新绝对安全；奖励变高也不一定代表机器人走得自然、稳定或更安全，必须单独评估成功率和物理指标。

03 · 连续动作策略与关节控制

连接算法与机器人

机器人动作通常是连续值，而不是上下左右这样的离散选项。策略网络常输出高斯分布的均值与标准差，再从分布中采样动作。

at ~ 𝒩( μθ(st), diag(σ²) )

一种常见的关节位置控制接口是：

qtarget = qdefault + saat
τ = Kp(qtarget − q) − Kdq̇

策略动作可能表示关节位置偏移、目标位置、速度或力矩；必须检查具体任务配置，不能默认所有环境都采用同一种定义。

动作形式优点 / 直觉需要留意
目标关节位置通常容易与 PD 控制器结合依赖底层控制器与增益
目标关节速度适合速度控制接口需要处理速度限制与积分漂移
关节力矩控制更直接对动力学、执行器模型和训练稳定性要求更高

需要掌握

  • 策略均值、标准差与探索的关系。
  • 动作归一化、缩放、裁剪与关节限位。
  • 观测归一化与动作归一化为什么重要。
  • 策略控制频率与仿真物理步长的区别。

训练问题排查顺序

  1. 确认 observation/action 的 shape、范围、单位正确。
  2. 检查 reward 是否有 NaN、无穷大或某一项压倒其他项。
  3. 查看 episode length、成功率、摔倒率，而不只看总奖励。
  4. 检查策略熵、KL、value loss、梯度范数。
  5. 固定随机种子做对照实验，避免凭单次结果下结论。

05 · 控制理论：PID、PD 与反馈

底层控制

强化学习策略常与传统控制器组合。策略可以给出目标关节位置，PD 控制器根据位置和速度误差计算力矩。

τ = Kp(qtarget−q) − Kdq̇

这里的简式假设目标速度为零；更一般的 PD 控制会同时使用目标位置和目标速度。实际系统还可能包含重力补偿、前馈项、饱和限制等。

PID比例、积分、微分；先从单关节目标跟踪理解。
状态空间用状态变量描述系统动态，为稳定性分析做准备。
MPC基于模型滚动优化未来一段时间的动作。
阻抗控制通过设定力—位移关系调节接触柔顺性。

06 · 运动学、坐标系与姿态

机器人基础
  • 关节空间：用各关节位置 q 描述机器人姿态。
  • 笛卡尔空间：用末端位置和姿态描述目标。
  • 正向运动学：由关节配置计算末端位姿。
  • 逆向运动学：根据末端目标求可行的关节配置。
  • 雅可比矩阵：联系关节速度与末端速度，也用于分析局部运动关系。
ẋ = J(q) q̇

人形机器人还需要区分世界坐标系、机身坐标系、关节坐标系和足端坐标系。读代码时务必确认每个向量在哪个坐标系表达。

学习检查

  • 能解释关节位置与末端位置的区别。
  • 能区分四元数、欧拉角和旋转矩阵的用途与局限。
  • 能从代码中找到 base、world、body、foot 等坐标定义。

07 · 动力学、接触与平衡

人形机器人关键

动力学研究力、力矩与运动的关系。人形机器人需要处理多关节耦合、重力、惯性、足底接触与摩擦。

M(q)q̈ + C(q,q̇) + g(q) = τ + J(q)ᵀfcontact

这是概念性表达：具体方程形式取决于符号约定、接触建模与系统定义。

概念直觉行走中的意义
质心 CoM整体质量分布的平均位置与支撑区域和身体平衡相关
地面反作用力地面对足底的接触力支撑身体、产生加速与转向
摩擦限制接触面相对滑动的能力影响推蹬、转弯和足底打滑
支撑相 / 摆动相脚接触地面 / 脚在空中步态规划与稳定性分析
角动量描述旋转运动状态躯干、手臂和腿协同维持平衡
不要把“奖励高”直接等同于“物理上安全”。需要监测关节限位、力矩、接触力、足底滑动和摔倒情况。

08 · 人形机器人行走与全身控制

目标方向

从简单到复杂的任务顺序

  1. 站立与保持机身姿态。
  2. 跟踪前进速度与转向速度。
  3. 在不同指令下稳定行走。
  4. 应对轻微外部扰动和不同地面参数。
  5. 跟踪参考动作或学习专家示范。
  6. 扩展到全身动作、操作与移动协同。

典型观测与动作

观测可能包括机身角速度、重力投影、关节位置与速度、上一时刻动作、目标速度指令等。动作常对应关节目标位置偏移，但必须以具体任务实现为准。

奖励函数设计思路

r = wᵥ rvelocity tracking + wω ryaw tracking − wₐ‖a‖² − wₛ rslip − w꜀ rcollision

可能还要考虑机身姿态、能耗、关节限制、足部接触和任务成功。先确认每项奖励的量纲、范围与符号，再调权重。

评价指标

  • 速度跟踪误差、转向跟踪误差。
  • 摔倒率、平均存活时间、任务成功率。
  • 足底滑动、关节力矩、能耗或动作平滑性。
  • 多个随机种子和未见过的环境条件下的表现。

09 · 仿真平台与 Isaac Lab

实战工具

推荐先运行官方现成任务，再逐步改代码。学习重点是看懂任务结构，而不是一开始就从零搭建整个物理环境。

环境 / Task定义场景、机器人、重置逻辑与仿真步进。
Observations决定策略能看到哪些状态、如何归一化。
Actions定义策略输出的含义、缩放和控制接口。
Rewards定义目标行为和惩罚项。
Terminations定义摔倒、越界、成功和超时等条件。
Agent config配置 PPO、网络、采样、学习率与训练轮次。

建议的项目操作顺序

  1. 记录 Isaac Lab、仿真器、CUDA、PyTorch 的版本。
  2. 运行一个官方任务的最小训练命令。
  3. 保存日志、配置文件和 checkpoint。
  4. 用训练好的策略单独评估，确认推理流程正常。
  5. 只修改一个变量，重新训练并对比指标。
安装命令会随 Isaac Lab 版本、操作系统与服务器环境变化。优先遵循所选版本的官方安装说明，不要混用不同版本的教程。

10 · 鲁棒性与 Sim-to-Real

进阶研究

仿真与真实世界存在差异：质量、惯量、摩擦、执行器延迟、传感器噪声和接触模型都可能不完全一致。

  • 域随机化：训练时随机改变部分物理参数或观测噪声。
  • 系统辨识：通过数据估计真实系统的动力学参数。
  • 鲁棒性评估：在未见参数、扰动与地形下测试策略。
  • 安全约束：设置关节位置、速度、力矩与工作空间限制。
  • 部署监控：监测状态异常、动作异常和策略失效。
真实人形机器人测试具有摔倒、夹伤和设备损坏风险。先在仿真中验证，部署时使用合适的支撑、防护、急停和保守的动作限制；不要直接把未经验证的策略用于真实机器人。
